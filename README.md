# 🎯 Retail Sales Predictor — Intelligent Forecasting System
*Forecast. Plan. Optimize. Faster.*

🔴 **Live Demo** → https://sales-prediction-azo7.onrender.com

## Overview
ML-powered sales prediction system that automatically forecasts weekly store sales based on environmental conditions, economic indicators, and promotional events.

## Features
- Weekly sales forecasting per store and department
- Economic indicator integration (CPI, Unemployment, Fuel Price)
- Markdown and promotional impact evaluation
- Holiday effect detection
- Real-time REST API endpoint for predictions
- Web-based interactive form

## Tech Stack
- Python, NumPy, Scikit-learn
- Flask, HTML, CSS
- Joblib (Model Serialization)
- Machine Learning Regression Model
